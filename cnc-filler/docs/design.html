Заполнитель свойств CNC

Программа для Windows: вы даёте один артикул или Excel со списком, она находит товары в базе каталогов и отдаёт Excel в формате выгрузки Битрикса с заполненными свойствами. Работает офлайн и берёт значения только из каталога или из самого артикула.

Как это работает

Путь от артикула до Excel

1 · ВводАртикул или ExcelExcel из 1С/Битрикса с колонками «Артикул», «_Код товара», «Бренд» и свойствами
2 · НормализацияЧистка артикулаS40T-MSKNR12, S40TMSKNR12 и «s40t msknr 12» дают один ключ; O/0, I/1 при OCR
3 · ПоискБаза каталоговТочное совпадение → R/L в одной строке каталога → серия + размер. Бренд учитывается
4 · РасшифровкаПравила ISOБуква длины (M=150), ISO 1832 для пластин, S = A − d/2 для PTHK
5 · ШаблонКолонки сайтаПараметры каталога раскладываются в колонки Битрикса: d → «Ø25», Dmin → две колонки
6 · ВыводExcel для 1СТолько пустые ячейки, код текстом с нулями, без пустот, листы «Источники» и «Не найдено»
База данных

Структура базы

Один файл SQLite рядом с программой. Обновить базу можно заменой файла, установка не нужна. Каталоги, их страницы, товары и параметры лежат отдельно от того, как они выглядят на сайте. Поэтому при смене колонок сайта меняется только шаблон, а база остаётся прежней.

Правила заполнения

Что программа делает и чего не делает

Делает

  • Заполняет только пустые ячейки. Значения из 1С не трогает, расхождения выносит на отдельный лист.
  • Выдаёт файл без пустых ячеек, чтобы загрузка не стёрла данные в 1С.
  • Пишет код товара текстом с нулями (00122573).
  • Указывает у каждого значения источник: каталог и страницу, артикул или формулу.
  • Пересчитывает _SEO_Sort шагом 10 по выбранному полю (например, по L).
  • Подставляет значения только из справочников 1С.

Не делает

  • Не берёт значения от соседнего размера и не угадывает. Если в каталоге нет, ячейка попадает в «Не найдено» с причиной.
  • Не ходит в интернет и не отправляет данные никуда.
  • Не меняет 1С напрямую: выдаёт Excel, который вы загружаете сами.

Excel на выходе

Лист «Загрузка» с колонками вашего шаблона. Лист «Источники» с каталогом и страницей у каждой ячейки. Лист «Расходится с каталогом». Лист «Не найдено» с причиной.

Один артикул

Карточка со всеми параметрами, каталогом и страницей. Кнопка «Копировать строку» копирует данные для вставки в Excel.

Управление базой

Вкладка «Каталоги»: список, сколько товаров разобрано, когда обновлено. Сюда же добавляются новые шаблоны сайта по выгрузке-образцу.

Наполнение базы

Самая большая часть работы

Программа быстро станет рабочей, а наполнение базы займёт время.

Почти все каталоги сканированные, около 2 000 страниц таблиц. Надёжно извлечь цифры из скана можно только так: я разбираю таблицу и сверяю её с картинкой страницы. Так уже сделаны MetalCraft (расточные и резьбовые), PTHK и Huareal (пластины). Автоматический OCR без сверки даёт ошибки в цифрах, а с такими данными программа будет «выдумывать».

Предлагаю наполнять базу по группам товаров в порядке ваших задач. Первая очередь — все токарные державки MetalCraft, Youyiqie, SANT и PTHK, затем пластины, свёрла и фрезы, оснастка. Каждая группа приходит обновлённым файлом базы, программу переустанавливать не нужно.

Что нужно от вас для MVP

  • Аккаунт GitHub (или создадим новый). Туда ляжет код и оттуда скачивается .exe.
  • По одной выгрузке Битрикса на каждую группу товаров. Это образец колонок шаблона, как iblock_element_admin по свёрлам.
  • Справочники 1С по полям со списками: тип пластины, покрытие, материал, вид обработки, тип державки.
  • Ваше «ок» или правки по структуре и окну на этой странице.
